# MyKnow 无人机资料库

查阅好盈 **H15 Plus / H15MD Plus** 参数、接线、保护和拉力对照。

## 手机上直接用（不用下 APK）

用手机 Chrome 打开：

https://raw.githack.com/1314520alu/myknow/cursor/drone-knowledge-android-4c9d/docs/index.html

打开后点浏览器菜单里的 **安装应用** / **添加到主屏幕**，就会出现在桌面，和普通 App 一样打开。

## APK（可选）

需要原生安装包时再用 `release/MyKnow.apk`。


查电机、电调、动力套参数的安卓 App。当前内置 **好盈 H15 Plus / H15MD Plus** 官方规格、接线、保护说明和 24S 拉力对照。

## 安装

1. 下载 `release/MyKnow.apk`
2. 手机打开「允许安装未知来源」
3. 点 APK 安装

最低系统：Android 8.0（API 26）

## 打开工程

用 Android Studio 打开本仓库，同步 Gradle 后运行 `app`。
